### 🔖 Советы по ведению заметок:

- Используйте заголовки разного уровня (`#`, `##`, `###`) для удобной навигации.
- Применяйте маркированные списки (`-`) и нумерованные списки (`1.`) для структурирования шагов и рекомендаций.
- Добавляйте кодовые блоки (`\```bash\nкоманда\n\````) для команд и скриптов.
- Выделяйте важные моменты жирным шрифтом (`**важный текст**`) или курсивом (`*интересный нюанс*`).
- Используйте горизонтальные линии (`---`) для разделения крупных блоков информации.

Такой подход обеспечит удобство и эффективность при ведении заметок, позволяя быстро находить нужную информацию и систематизировать опыт работы с Zabbix.
